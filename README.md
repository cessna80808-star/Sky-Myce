# Sky-Myce

Sky-Myce is a client-side Fabric mod for Hypixel SkyBlock. It adds dungeon tools, useful HUD widgets, tracking, and optional community features.

**Current release:** 2.5.15 · **Minecraft:** 26.1.2 · **Java:** 25

## Install

Download the [latest release](https://github.com/cessna80808-star/Sky-Myce/releases/latest), close Minecraft, and put the standalone mod JAR in your Fabric instance's `mods` folder alongside its Fabric dependencies. Launch the game and open `/sm` to configure features.

If you are migrating from the old Loader setup, remove the old Sky-Myce Loader and mod JAR first. Keep your other mods and settings.

## What’s included

- Dungeon tools: Party Finder matching, missing-player alerts, chest safeguards, routing, and camera controls
- Personal dungeon and RNG tracking
- Daily Digest, Auto Refill, stash assistance, and HUD widgets
- Friend and party coordination, plus optional Global Chat and community sharing
- Local cosmetics and optional signed updates

Local features work without Discord or the optional community service. See the [Player Guide](MANUAL.md) for setup, commands, and help.
